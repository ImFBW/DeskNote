# DeskNote 使用说明书

DeskNote 是放在桌面上的便签。平时只把数据写在这台电脑的 SQLite 里，不需要登录。想把便签同步到自己的服务器时，再登录。Windows 和 macOS 用同一套程序；安装包需要在对应系统上编译。

## 1. 安装

### Windows

双击 `DeskNote-Setup-1.0.0.exe`，按提示选择目录。安装后开始菜单和桌面会有 DeskNote。

如果是从源码运行，需要 Node.js 22.12 或更新版本：

```text
npm install
npm start
```

后台管理单独启动：

```text
npm run server
```

浏览器打开 `http://127.0.0.1:8787`。

### macOS

在 Mac 上执行 `npm run dist:mac`，得到 `dist` 目录里的 dmg。打开后把 DeskNote 拖进应用程序文件夹。全局快捷键如果没有反应，到「系统设置 → 隐私与安全性 → 辅助功能」里允许 DeskNote。

本机是 Windows 时不能直接打出 macOS 安装包，需要把项目拷到 Mac 上再执行上面的命令。

## 2. 第一次打开

程序会放一张欢迎便签、三个分类（工作、生活、灵感）和一张示例待办。示例提醒默认是关闭的，不会突然响。

关闭主窗口时，程序留在托盘里，桌面上的便签还在。从托盘图标可以重新打开，或选择「退出」。

数据在：

- Windows：`%APPDATA%\DeskNote`
- macOS：`~/Library/Application Support/DeskNote`

数据库文件是 `desknote.sqlite`。操作日志和错误日志在同目录的 `logs` 文件夹，设置页也能打开。

## 3. 便签和 Markdown

左侧是分类，中间是列表，右边写内容。支持：

- 标题、粗体、斜体、行内代码和代码块
- 列表、任务列表、引用、表格和链接
- 表情。点右侧表情即可插入，也可以用系统的表情面板

编辑会在停顿后自动保存。`Ctrl+S` 会立刻保存。搜索是 `Ctrl+F`。

纸色、列表置顶、归档都在右侧。归档后的便签从「已归档」里找。

## 4. 分类、待办、提醒

分类可以新建和删除。删掉分类不会删便签，只是便签变为未分类。

待办是一种便签，里面每一项可以单独勾选。

提醒可以只响一次，也可以每天、每周、每月，或按分钟间隔重复。每周用 0 到 6 表示周一到周日，例如工作日是 `0,1,2,3,4`。

到点后右下角出现气泡，大约 8 秒后消失。设置里允许提示音时，会同时响一声短音。程序没开着的时候不会补响很久以前的提醒；重新打开后，只补最近 12 小时内错过的那一次。

「提醒」页的「立即检查」不用等下一次轮询。

## 5. 放到桌面、置顶、穿透

打开桌面便签后，这张纸条会单独浮在桌面上，位置和大小会记住。

- **放到桌面**：打开这张独立纸条。
- **窗口置顶**：压在其他窗口上面。
- **贴**：把卡片贴进桌面层。它会留在壁纸和图标之上，普通窗口盖住它；按 Win+D 显示桌面时它还在。和「置顶」只能开一个。
- **穿**：鼠标穿透，点击会落到桌面或下面的窗口。开启后这张卡片收不到点击，用 `Ctrl+Alt+P`、桌面条上的「关闭全部穿透」或托盘里的同名菜单关掉。
- **锁**：锁定位置和大小，卡片不能再被拖走。
- **外观**：每张卡片可以改背景色、透明背景、字体、字号、粗体、斜体和整张卡片的不透明度。
- **上限**：桌面上同时放下的便签、待办、提醒合计有上限，默认 8，可在桌面条或设置里改成 1 到 30。

启动后先看到右上角的桌面条，不必打开主窗口也能新建、修改和删除。主窗口仍可从桌面条或托盘打开。设置里可以改成启动时显示主窗口。

不透明度最低约 15%。透明背景只去掉纸色，字仍然看得见。

## 6. 快捷键

默认：

| 动作 | 按键 | 范围 |
| --- | --- | --- |
| 新建便签 | Ctrl+Alt+N | 全局 |
| 新建待办 | Ctrl+Alt+T | 全局 |
| 显示或隐藏主窗口 | Ctrl+Alt+Space | 全局 |
| 切换鼠标穿透 | Ctrl+Alt+P | 全局 |
| 立即同步 | Ctrl+Alt+S | 全局 |
| 搜索 | Ctrl+F | 窗口内 |
| 保存 | Ctrl+S | 窗口内 |
| 使用说明 | F1 | 窗口内 |

设置页可以改。点「录制」后按下想用的组合。全局快捷键如果被别的软件占用，错误日志里会有 `hotkey.bind`。

## 7. 同步

不登录时，所有内容只在本机。设置页填服务器地址、用户名和密码：

- 没有账号就点「注册并登录」
- 已有账号点「登录」
- 「立即同步」或自动同步间隔会上传本地变更，并拉回服务器上更新的内容

同一条内容两边都改过时，以较新的修改时间为准。密码和登录令牌不会写进操作日志。令牌保存在本机数据库里。

后台默认同时听 `127.0.0.1` 和 `localhost`。要给别的电脑用，启动前设置环境变量 `DESKNOTE_HOST=0.0.0.0`，并自己做好访问控制。

## 8. 网页后台

后台给管理员看同步用户和运行情况，不代替桌面便签。

桌面端启动时会在本机 `8787` 端口同时启动后台。也可以单独运行 `npm run server`。

1. 打开 `http://127.0.0.1:8787` 或 `http://localhost:8787`。不要直接双击 `index.html`，否则登录会显示 Failed to fetch。
2. 第一次的管理员账号默认是 `admin`，密码写在数据目录的 `initial_admin.txt`。也可以事先设置 `DESKNOTE_ADMIN_PASSWORD`。
3. 登录后先到「账号」修改密码。

如果登录提示连不上接口，说明 8787 端口上没有服务。先启动 DeskNote，或在项目目录执行 `npm run server`。

后台可以：

- 看用户、便签数量和最近一天的日志数量
- 停用用户、重置密码。停用后该用户不能再同步
- 按标题查看已同步的便签内容
- 查看提醒、操作日志和错误日志

同步上来的正文管理员看得到。只想留在自己电脑上的内容，不要登录同步。

## 9. 日志

两类日志都有：

- 操作日志：新建、修改、删除、同步、登录、开关穿透、提醒触发
- 错误日志：失败时的原因和堆栈

自动保存写文件日志；数据库里的操作日志会把同一张便签的连续自动保存合并，避免列表被刷满。日志文件超过约 2MB 会滚一份备份。主窗口的「日志」页可以筛选和导出。

## 10. 资源占用

界面不用额外的前端框架。数据库、提醒和快捷键都在主进程里，提醒大约 15 秒看一次，同步检查大约 60 秒一次，没有到期项时几乎不做事。

桌面纸条在失去焦点后把刷新率降到大约 4 帧，避免一直占着 CPU。不用的气泡窗口会关掉，不常驻。关闭硬件加速是为了少一个常驻的图形进程；纸条以文字为主，这样更省内存。

## 11. 打包

Windows 安装包：

```text
npm run dist
```

结果在 `dist` 目录，文件名类似 `DeskNote-Setup-1.0.0.exe`。

macOS：

```text
npm run dist:mac
```

## 12. 遇到问题时

- 主窗口关了但还在：看任务栏右下角或菜单栏的托盘图标。
- 穿透之后点不到纸条：按 `Ctrl+Alt+P`。
- 固定到桌面后纸条位置不对：关掉「固定到桌面」，改用「窗口置顶」。错误日志里如果有 `platform.load` 或 `window.pin_refresh`，说明系统没有允许挂到桌面层。
- 同步失败：先看服务器是否已启动、地址是否带 `http://`。登录失效时重新登录。
- 忘了管理员密码：还没改过就看 `initial_admin.txt`。已经改过又忘了，只能在停掉服务后处理服务器数据库，或删掉服务器数据目录重新初始化。这会清掉服务器上的同步数据，电脑里的本地便签还在。
- 快捷键没反应：换一个组合，或看错误日志里的 `hotkey.bind`。
